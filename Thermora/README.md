# Thermora – Temperature Intelligence

Thermora is a temperature conversion and analysis web application built using HTML, CSS, and JavaScript.

## Features

- Temperature conversion between multiple units
- Celsius, Fahrenheit, Kelvin, Rankine, Réaumur, Delisle, and Newton scales
- Compare two temperatures
- Temperature analysis and classification
- Formula Lab to understand conversion calculations
- Conversion history using browser local storage
- Visual temperature scale
- Copy conversion results
- Swap temperature units
- Responsive design

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Local Storage API
